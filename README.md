# Personal Portfolio Website

A responsive single-page portfolio built with plain **HTML, CSS and JavaScript** — no framework or build step.

## Sections

- **About me** — profile photo and short introduction
- **Skills** — HTML, JavaScript, React, Node.js, CSS
- **Projects** — showcase cards
- **Recommendations** — visitors can add a recommendation through a form; it is appended to the page instantly with JavaScript

## Run

Open `index.html` in a browser. To publish it, enable **GitHub Pages** for the `main` branch (root folder).

## Project structure

```
├── index.html      # page structure
├── css/style.css   # layout and styling
├── js/script.js    # recommendation form logic
└── images/         # profile photo and skill icons
```
